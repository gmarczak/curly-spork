# Checklista Assetów Graficznych — per Produkt

Wymagane grafiki przed uruchomieniem kampanii:

- [ ] Logo/wordmark marki produktowej (wygenerowane przez Agenta Onboardingu/Brandingu)
- [ ] Zdjęcia produktowe główne (min. 3, tło neutralne) — FLUX.1 via Fal.ai/Replicate lub zdjęcia od dostawcy
- [ ] Zdjęcia lifestyle (produkt w użyciu, kontekst grupy docelowej)
- [ ] Grafiki pod reklamy Meta (format 1:1 i 4:5, min. 3 warianty)
- [ ] Grafiki/wideo pod TikTok (format 9:16, min. 3 warianty)
- [ ] Favicon i grafika OG (social share) dla storefrontu

## Uwaga kosztowa

Generowanie grafik AI: ~2–5 USD jednorazowo per produkt (patrz `01_FINANSE_I_PRAWO/Koszty_Infrastruktura/Budzet_Startowy_i_Prognoza.md`). Pliki finalne zapisuj w tym folderze w podfolderach `01_Produktowe/`, `02_Lifestyle/`, `03_Ads_Meta/`, `04_Ads_TikTok/`.
